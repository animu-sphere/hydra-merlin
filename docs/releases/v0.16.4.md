# v0.16.4 - Forward exposure and tone mapping

**Release date:** 2026-10-18 (JST)
**Tag:** `v0.16.4`

## Release theme

v0.16.4 adds one renderer-neutral output transform for lit Forward: exposure in
EV followed by selectable None or Reinhard tone mapping into the linear Color
AOV. Vulkan, Metal, Hydra and the native viewport interpret the same contract,
and the default 0 EV/Reinhard preserves the v0.16.2 rendered meaning.
Independent Vulkan and Metal device and host evidence closes this output-policy
milestone. The Mesh surface shading contract, representative quality and
material parity remain the next v0.16.x milestones.

## Completed scope

- `RenderRequest::output_transform`, `RendererSettings`, Hydra
  `merlin:exposureEv`/`merlin:toneMapping` and the viewport controls select EV
  in `[-32, 32]` and None/Reinhard per frame. Invalid EV, unknown modes and
  ACES are rejected before submission. Alpha, depth, IDs, clear color, unlit
  diagnostics and Gaussian compositing keep their existing policy.
- Core validates and packs the output record for conventional, bindless,
  GPU Scene, GPU-driven and generated Vulkan Forward, and native Metal Forward.
  Output-only edits require no geometry upload, allocation or new pipeline.
  Backend contract 4 and shader ABI 11 require rebuilt consumers and artifacts.
- The GPU capability workflow now requires executed native Vulkan output gates
  and a MaterialX-enabled Debug/Release generated Forward build, and the
  offline backend comparator compares host exposure/tone-mapping reports.
- The [surface geometry contract](../design/surface-geometry.md) defines the
  normal, tangent-frame and normal-mapping semantics for the next milestones.

## Compatibility and limitations

Default output is unchanged. Rebuild SDK consumers, shader artifacts and
binaries for backend contract 4 and shader ABI 11. None clips at the RGBA8 AOV;
ACES, HDR output, OCIO/ICC conversion, gamut mapping and complete color
management are unsupported. Output evidence comes from analytic fixtures and
host center/image comparisons on RTX A5000 and Apple M3; representative-scene
exposure quality, full-image cross-backend parity and other hardware are not
established.

SDK assets remain Windows/Linux Core and macOS Apple Silicon Core + Metal.
Vulkan, Hydra and MaterialX runtime products remain source-build products.
