# v0.14.1 - Gaussian correctness MVP

**Release date:** 2026-08-02
**Tag:** `v0.14.1`

## Objective

v0.14.1 adds a correctness-first Gaussian-splat rendering path from Hydra's
standard `particleField` Rprim through host-neutral resources to Vulkan
projection, rasterization, and picking.

## Completed capabilities

- Standard OpenUSD 26.05/26.08 `ParticleField3DGaussianSplat` ingestion with
  float-over-half attribute selection, normalized covariance, opacity, and
  degree-0-3 spherical-harmonic payloads.
- Immutable host-neutral Gaussian resources with revision tracking and
  normalized changed-particle ranges for localized downstream updates.
- Deterministic CPU camera-space preparation, projection, culling,
  back-to-front sorting, and degree-0-3 real spherical-harmonic evaluation.
- Procedural Vulkan ellipse rasterization with authored opacity and radiance,
  mixed Mesh depth composition, and dedicated Gaussian resource/particle ID
  picking.
- Completion-safe packed-stream uploads with static-frame cache reuse and
  telemetry for preparation, sorting, uploads, draws, and fallback behavior.
- A repository-owned CC0 8,192-particle degree-3 USD corpus, reference image,
  Tier 0 and HgiVulkan usdview comparison gates, and native viewport evidence.

## Compatibility

- Gaussian splats use Hydra's standard `particleField` Rprim; no custom USD
  schema or direct PLY/SPLAT parser is required.
- The v0.14.1 implementation is available through the Vulkan renderer path.
  Persistent device-local Gaussian resources remain planned for v0.15.0, and
  GPU-driven projection and sorting remain planned for v0.16.0.
- HgiVulkan retains its asynchronous color GPU-copy path, while Tier 0 CPU
  RenderBuffers remain the universal host-presentation fallback.

## Known limitations

- Gaussian transparency uses the deterministic CPU sort established by this
  release; GPU-driven preparation and sorting are not yet implemented.
- The current path is a correctness MVP, not a claim of persistent
  device-resident Gaussian resources or draw-count-independent submission.

## Verification evidence

- Core, Vulkan, and Hydra tests cover ingestion, normalization, preparation,
  raster behavior, picking, localized uploads, static cache reuse, and shader
  artifact/ABI contracts.
- Tier 0 and forced-HgiVulkan usdview smoke coverage validates the bundled
  corpus against its reference capture with zero renderer-owned Vulkan
  validation diagnostics.
