# v0.16.7 - Forward interior validation and usdview controls

**Release date:** 2026-11-23 (JST)
**Tag:** `v0.16.7`

## Completed scope

- usdview's Scene Lights, Default Camera Light and Default Dome Light feed
  independent inputs to Hydra Forward. The default dome uses OpenUSD's
  Stinson Beach HDR for diffuse illumination and the viewport background.
  Dome camera visibility controls the background independently.
- Merlin consumes usdview's nine Mesh display modes on Vulkan and Metal,
  including wireframe overlays, hidden-surface wireframe, and point sprites.
  Wireframe uses authored polygon edges and geometry-only uses display color.
- The external Forward scene gate accepts world-space camera recipes for
  Kitchen_set's sink and cabinets. A pinned OpenStrata Formation exercises
  Gaussian PLY import and the Merlin render delegate on Windows.

## Compatibility and limitations

Backend contract 7 and shader ABI 14 require rebuilt SDK consumers, shader
artifacts and binaries. SDK assets are Windows/Linux Core and macOS Apple
Silicon Core + Metal. Vulkan, Hydra and MaterialX runtime products remain
source-build products.

The Kitchen_set gate checks the two configured routes and first-frame
correctness. The asset carries display colors. The separate material probe
retains diffuse-only shading and exposed a PNG decoding limit. Full-image
Vulkan/Metal parity, unrestricted interactive navigation, and broader
material coverage remain open. See the
[support matrix](../reference/support-matrix.md#forward-lighting-and-output)
and [current roadmap](../roadmap/current.md).
