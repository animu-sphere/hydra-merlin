# v0.16.5 - Mesh surface normal contract

**Release date:** 2026-10-18 (JST)
**Tag:** `v0.16.5`

## Release theme

v0.16.5 implements and validates the normal part of the
[surface geometry contract](../design/surface-geometry.md). Core prepares Mesh
normals for native and Hydra meshes with one priority. Every Vulkan and Metal
Forward entry builds the same Slang surface context, so mirrored instances,
`leftHanded` orientation and double-sided back faces shade from the visible
side on both backends. Tangent frames, normal mapping, representative quality
and material parity remain the next v0.16.x milestones.

## Completed scope

- Core prepares corner normals with an authored → generated → `Ng` priority.
  Degenerate authored normals fall back to `Ng` with a
  `mesh.normals.degenerate` diagnostic. Native meshes without normals now use
  generated smooth normals instead of `+Z`.
- Conventional, bindless, GPU Scene, GPU-driven and generated Vulkan Forward,
  and native Metal Forward, build `Ng`, `Ns_base`, `Ns` and facing in one
  shared Slang surface context.
- Negative-determinant instances reverse the effective winding per draw.
  Hydra Mesh `doubleSided` is ingested, and double-sided back faces flip
  `Ng` and `Ns_base`.
- The `geometric-normal`, `shading-normal-base`, `normal` and `front-facing`
  debug views run through renderer settings, render requests, the Hydra
  `merlin:debugView` setting and the native viewport.
- Analytic native surface fixtures and a usdview normals fixture cover these
  rules. The GPU capability workflow requires them. The external Forward scene
  gate now runs Kitchen_set on Metal.

## Verification evidence

- [Capability run 39076397323](https://github.com/animu-sphere/hydra-merlin/actions/runs/39076397323)
  on `1eaad14` (renderer tree identical to the release) runs on RTX A5000. The
  analytic surface gate passes conventional, bindless, GPU Scene and GPU-driven
  Vulkan Forward within 1/255 in Debug and Release. The usdview normals fixture
  passes Tier 0/HgiVulkan with exact centers, and the MaterialX-generated
  Forward build passes in Debug and Release.
- On Apple M3, the 13 analytic cases pass native Metal conventional and GPU
  Scene within 1/255. The usdview normals fixture passes Tier 0/HgiMetal with
  identical centers. All 24 usdview normals centers agree between RTX A5000
  Vulkan and Apple M3 Metal within 1/255 in both presentation modes.
- Kitchen_set has 1,788 meshes without authored normals, 363 of them
  `doubleSided`. Compared with v0.16.4 on Tier 0/HgiMetal, its images change by
  at most 5 of 120,701 pixels. Repeated runs of one build vary by 0–2 pixels.
  An X-mirrored Kitchen_set, which v0.16.4 culls from the wrong side, keeps
  exact front-facing and X-negated world normals. See the
  [representative-scene evidence](../reports/delivery-history.md#v0165-representative-scene-normal-evidence--2026-10-18).
- Fresh local Release builds pass without skips: Core 25/25, native Metal
  39/39 and Metal/Hydra 69/69. The Metal/Hydra run includes the Kitchen_set
  Tier 0/HgiMetal scene gate, whose 649 image pairs differ by at most 5 pixels.

## Compatibility and limitations

Native meshes without normals now shade with generated smooth normals rather
than `+Z`. Mirrored single-sided geometry and Hydra `doubleSided` meshes now
render from the correct side. Rebuild SDK consumers, shader artifacts and
binaries for backend contract 5 and shader ABI 12.

Tangents, tangent-space normal maps, derivative tangent frames and tangent
debug views are unsupported until v0.16.6. MaterialX `normal` accepts only an
already constructed world-space normal. Representative-scene evidence comes
from Kitchen_set viewpoints on Apple M3; it is not a pixel-exact gate or
interior-quality evidence.

SDK assets remain Windows/Linux Core and macOS Apple Silicon Core + Metal.
Vulkan, Hydra and MaterialX runtime products remain source-build products.
