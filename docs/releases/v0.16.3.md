# v0.16.3 - Backend modules and shared Forward shader policy

**Release date:** 2026-10-13 (JST)
**Tag:** `v0.16.3`

## Release theme

v0.16.3 separates backend execution responsibilities and gives Core one
canonical Forward policy while preserving the v0.16.2 rendering semantics.
Independent device and host evidence closes the architecture verification
phase; exposure/tone mapping, representative quality and material parity remain
the next v0.16.x milestones.

## Completed scope

- Vulkan and Metal implementations are split into execution, Forward,
  Gaussian, GPU Scene, pipeline, resource, readback and presentation units.
  Core owns shared draw transforms, material packing and Slang shading/table
  policy; backend entry points orchestrate execution.
- Native Metal Forward, GPU Scene, color conversion and presentation use
  build-time Slang artifacts, reflection/checksums and embedded metallibs.
  Installed SDK consumers retain both Forward and Gaussian libraries, emitted
  sources and reflection. Boundary and ABI checks cover the shared policy,
  native uploads, table strides and presentation bindings.
- Documentation has explicit ownership and lifecycle rules, a capability
  status/limitations matrix, focused viewport/Forward validation guides, and
  CI checks for repository-relative links and incomplete-only current tasks.

## Compatibility and limitations

The refactor preserves public backend entry points, GPU ABI, resource/completion
ownership, fallback selection and supported material coverage. Rebuild static
SDK consumers to pick up the shared Core helpers and packaged shader artifacts.
Existing SH/Reinhard lighting and Camera Light OFF diagnostic fallback remain
unchanged. Center parity does not establish full-image cross-backend raster
parity, broader GPU/SDK support, generated Metal ingestion, selectable exposure/
tone mapping, unrestricted navigation or representative Kitchen quality.

SDK assets remain Windows/Linux Core and macOS Apple Silicon Core + Metal.
Vulkan, Hydra and MaterialX runtime products remain source-build products.
