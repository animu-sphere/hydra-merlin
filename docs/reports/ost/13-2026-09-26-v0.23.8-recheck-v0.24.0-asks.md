  attempt, resume offset, idle age, and verification step, then imported the
  artifact. hdMerlin's ORAS/curl download workaround is removed.

  core build, managed test, managed `renderer viewport` session, and
  `ost validate` all completed. Renderer assertions are bound to `ost-test` and
  `ost-build` completion records by path and SHA-256, and the viewport session
  wrote a durable launch record scoped to its build directory.

  its `ost-test` binding fails on digest mismatch. A report claiming a
  nonexistent `ost-build` session fails as unbound. An unchanged managed build
  does not rebind a report it did not write.
- One hdMerlin defect was found and fixed. A direct `merlin-headless` run
  labeled its report `kind: "managed"` with a stale `hdMerlin 0.9.0` target.
  OST correctly treated it as unverified external evidence. However, the
  validation verdict gave no sign of that difference, which leads to the
  second v0.24.0 ask.
- Both previously pinned runtime OCI manifests now return 404, and the tag
  scheme changed without a migration note. CI is repinned to the current

## Findings

| ID | Priority | Finding | Requested v0.24.0 outcome |
| --- | --- | --- | --- |
| OST24-RND-001 | P1 | Published runtime manifest digests pinned by downstream CI disappeared from GHCR, and the tag scheme changed without a migration record | A documented retention window for superseded runtime digests, plus an old→new digest and tag migration record when a runtime family is republished |
| OST24-RND-002 | P2 | `ost validate` shows a harness- or externally-produced report in a managed tree the same way as a completion-bound report, apart from its producer ID | Each renderer check carries the producer kind and a verification class; a managed tree whose primary report is unbound, while a completion binds that path at another digest, reports a warning, or a failure under a strict flag |

### OST24-RND-001 acceptance criteria

- The runtime publishing guide states how long superseded manifest digests
  remain pullable after a republish.
- A republish produces a machine-readable record that maps previous tags and
  manifest digests to their replacements, with the reason for the change.
- A 404 for a digest-pinned pull says whether the registry lost the digest or it
  never existed, and links to the migration record when there is one.

### OST24-RND-002 acceptance criteria

- The JSON form of each `renderer.*` check includes `producer_kind` and one
  verification class, such as `completion-bound`, `attached-external`, or
  `unbound`.
- Human output makes an unbound PASS distinguishable from a completion-bound
  PASS without reading the report file.
- In an OST-managed build directory, a primary report whose producer is not
  bound by the current build or test completion produces a structured warning.
  An opt-in strict mode turns it into a failure.
- Non-`ost-*` producer kinds that imply management, such as `managed`, are
  reserved or rejected.

## Downstream CI disposition

The first self-hosted capability run at the new pins failed in all four jobs
before CMake configure. The failure came from the runner host, not from
OpenStrata. The runner registration had expired after a long idle period, and
once it was re-registered, the host had Visual Studio 2026 but no registered
Visual Studio 2022 instance. The workflow's pinned `Visual Studio 17 2022`
generator therefore could not find a compiler. Even in that run, the OpenUSD
26.05 job completed the ost 0.23.8 bootstrap, native pull, runtime
materialization, and runtime validation.

The workflow now omits `-G`, so CMake selects the newest installed Visual
Studio. The rerun,
[run 36218214278](https://github.com/animu-sphere/hydra-merlin/actions/runs/36218214278),
passed all four jobs:

- Vulkan 1.4 headless Debug and Release, including the Release
  `ost build` → `ost test` → `ost validate` lifecycle;
- OpenUSD 26.05 and 26.08 HgiVulkan, each with an uncached native
  `ost artifact pull` under the strict consumer gate. The archive layers
  transferred in 2.3 s and 8.2 s, each on the first attempt. Discovery, bridge,
  RenderBuffer, viewport, Tier 0 usdview, and HgiVulkan smoke and comparison
  regressions then passed.
